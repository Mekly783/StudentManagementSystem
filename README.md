**Student Management System – OOP Project**

This project implements a simple Student Management System using Java and Object-Oriented Programming principles.

**OOP Concepts Demonstrated:**

Encapsulation (private attributes with getters and setters)

Inheritance (Student extends Person)

Polymorphism (Method overriding)

Abstraction (Abstract class Person)

**The system captures:**

Student ID

Name

Course

Marks

It calculates and displays the student's grade based on marks.
